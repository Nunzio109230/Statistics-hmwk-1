04 · Interpretation

Which properties matter cryptographically?

The professor's key question: which observations relate to a one-way function, and which are specifically associated with hash functions?

Elliptic-curve scalar multiplication

Given a public base point G and scalar k, computing Q = kG is deterministic and efficient. Recovering k from Q and G is intended to be computationally infeasible for secure real-world curves and parameters; this is the Elliptic Curve Discrete Logarithm Problem (ECDLP).

Scalar multiplication supports public-key cryptography and digital-signature systems. Its one-way character does not mean it is a hash function: it operates on group elements and scalars and has algebraic structure.

Cryptographic hash functions

Cryptographic hashes map arbitrary-length input data to a fixed-length digest. Important goals include preimage resistance, second-preimage resistance and collision resistance. A small input change should typically cause a large, hard-to-predict digest change—often described as an avalanche effect.

Scalar multiplication does not need to provide hash-style avalanche behaviour or collision resistance. Its security rests on the ECDLP and the structure and parameters of the elliptic-curve group.

Important limitation: the toy curve over the field modulo 17 is tiny and completely insecure. Its points and scalar cycles can be enumerated, and discrete logarithms can be solved by simple search. It is useful only for learning the arithmetic.
